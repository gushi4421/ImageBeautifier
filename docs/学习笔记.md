## 一、RGBA 与透明度

RGBA 中的 **A** 表示透明度（Alpha），取值范围为 0-255：

- **0** 表示完全透明
- **255** 表示完全不透明

## 二、正向映射与反向映射

### 正向映射 (Forward Mapping)

遍历原图的每一个像素，通过矩阵乘法计算出它在目标图上的新坐标，然后把颜色赋过去。

**致命缺陷**：浮点坐标取整后，可能导致目标图上某些像素没有被赋到值，出现密密麻麻的"黑点"（空洞），或者多个原图像素挤在同一个目标像素上。

### 反向映射 (Backward Mapping)

遍历目标图像的每一个像素位置，通过变换矩阵的逆矩阵计算出它对应在原图的哪个坐标，然后把原图那个坐标的颜色"拿"过来。

**优势**：目标图的每一个像素都一定会被遍历到，绝对不会出现空洞。在写代码时，几乎全部采用反向映射。

## 三、图像旋转的数学原理

与简单的平移不同，旋转涉及到三角函数。

在二维笛卡尔坐标系中，假设要将一个点 $(x, y)$ 绕原点 $(0, 0)$ 逆时针旋转 $\theta$ 角度，到达新位置 $(u, v)$，其正向映射的数学公式为：

$$u = x \cos\theta - y \sin\theta$$

$$v = x \sin\theta + y \cos\theta$$

但为了避免图像出现空洞，必须使用反向映射。也就是说，已知目标图像上的点 $(u, v)$，要反推它在原图上的坐标 $(x, y)$。反向映射相当于把图像顺时针旋转回去（即角度变为 $-\theta$），代入并化简后得到反向映射公式：

$$x = u \cos\theta + v \sin\theta$$

$$y = -u \sin\theta + v \cos\theta$$

### 核心难点：坐标系转换

数学公式是绕着原点 (0, 0) 旋转的。但在计算机图像中，原点 (0, 0) 位于图像的左上角。如果直接套用公式，图像会绕着左上角旋转，大部分内容会直接转出屏幕外。因此，真正的逻辑需要三步走：

1. 将坐标原点平移到图像中心
2. 执行旋转计算
3. 将坐标原点平移回左上角

## 四、图像噪声

在数字图像处理中，最常研究的噪声有两种：高斯噪声与椒盐噪声。

### 高斯噪声 (Gaussian Noise)

符合正态分布（高斯分布）的随机噪声。其数学意义是：在图像的每一个像素点上，随机加上一个服从 $N(\mu, \sigma^2)$ 分布的数值。这种噪声通常来源于相机传感器的热噪声。

### 椒盐噪声 (Salt and Pepper Noise)

一种脉冲噪声。"椒"代表黑色的胡椒（像素值变为 0），"盐"代表白色的盐粒（像素值变为 255）。其数学逻辑是：设定一个概率 $P$，图像中的每个像素有 $P/2$ 的概率变成黑点，有 $P/2$ 的概率变成白点，其余保持原样。它通常由于模数转换器损坏或传输信号丢失引起。

## 五、大津法 (OTSU) — 自动阈值二值化

大津法的核心思想是：放弃人工猜测，让图像的像素分布（直方图）自己"告诉"我们完美的切割点在哪里。

### 数学原理：最大化类间方差

假设有一个阈值 $T$（取值范围 0 到 255），它把图像中所有的像素分成了两大阵营：

- **背景 (Class 0)**：灰度值 $< T$ 的像素
- **前景 (Class 1)**：灰度值 $\ge T$ 的像素

如何判断这个 $T$ 切得好不好？如果 $T$ 切得完美，那么背景内部和前景内部的颜色都应该尽量一致，而背景与前景两者之间的反差应该越大越好。这种"反差"，在数学上被称为 **类间方差 (Between-Class Variance)**。

### 推导过程

- 背景像素占比：$\omega_0$
- 前景像素占比：$\omega_1$（显然 $\omega_0 + \omega_1 = 1$）
- 背景平均灰度：$\mu_0$
- 前景平均灰度：$\mu_1$
- 整幅图像平均灰度：$\mu = \omega_0\mu_0 + \omega_1\mu_1$

最终的类间方差公式为：

$$\sigma^2 = \omega_0(\mu_0 - \mu)^2 + \omega_1(\mu_1 - \mu)^2$$

经过化简，它变成一个极其优美的乘法公式：

$$\sigma^2 = \omega_0 \omega_1 (\mu_0 - \mu_1)^2$$

这个公式的物理意义：只有当背景和前景的像素数量都足够多（$\omega_0$ 和 $\omega_1$ 的乘积大），并且两者的明暗反差足够强烈（$\mu_0 - \mu_1$ 的差值大）时，类间方差 $\sigma^2$ 才会达到最大。

### 算法流程

让阈值 $T$ 从 0 遍历到 255，分别计算每一次的类间方差 $\sigma^2$。那个让 $\sigma^2$ 最大的 $T$，就是我们要找的完美阈值。

## 六、uint8 溢出问题

如果 image 是 Numpy 默认读取的 uint8 格式（无符号 8 位整数，范围 0-255），灾难就会发生：

假设某个像素亮度为 200，想让它变亮，设置 $\beta = 100$：

$$200 + 100 = 300$$

但是在 uint8 的世界里，超过 255 的部分会发生截断/环绕 (Wrap-around)，即 $300 \pmod{256} = 44$。

结果：原本 200 的明亮像素，变亮之后居然变成了 44 的暗黑像素，图像上会出现可怕的彩色噪点斑块。

### 标准组合拳

任何涉及像素值增加或乘法放大的底层算法，**"先转 float → 再计算 → 后 clip → 最后转 uint8"** 是一套雷打不动的标准流程。

## 七、卷积核权重归一化的能量守恒证明

我们要证明的是：无论图像的内容多么复杂多变，只要卷积核的权重之和为 1，卷积操作就绝对不会改变图像的全局平均亮度。

### 1. 图像亮度的数学本质

图像 $I$ 是一个大小为 $M \times N$ 的二维矩阵。所谓"整体亮度"，其严谨的定义是整张图像所有像素值的数学期望（算术平均值）：

$$Mean = \frac{1}{M \times N} \sum_{x=0}^{W-1} \sum_{y=0}^{H-1} I(x, y)$$

因为图像尺寸 $M \times N$ 在模糊前后固定不变，所以证明"平均亮度不变"，完全等价于证明图像所有像素的 **总能量 (Total Energy)** 不变。

记原始图像的总能量为 $E_{in}$：

$$E_{in} = \sum_{x} \sum_{y} I(x, y)$$

### 2. 全局能量守恒的严谨证明

假设有一个任意的二维卷积核 $K(u, v)$，前提条件是所有权重之和为 1：

$$\sum_{u} \sum_{v} K(u, v) = 1$$

对整张图像进行卷积运算，输出图像 $O$ 在任意坐标 $(x, y)$ 处的像素值定义为：

$$O(x, y) = \sum_{u} \sum_{v} I(x+u, y+v) \cdot K(u, v)$$

计算输出图像 $O$ 的总能量 $E_{out}$：

$$E_{out} = \sum_{x} \sum_{y} O(x, y)$$

将 $O(x, y)$ 展开代入：

$$E_{out} = \sum_{x} \sum_{y} \left( \sum_{u} \sum_{v} I(x+u, y+v) \cdot K(u, v) \right)$$

根据富比尼定理 (Fubini's Theorem)，把关于 $u, v$ 的求和提到最外面：

$$E_{out} = \sum_{u} \sum_{v} K(u, v) \cdot \left( \sum_{x} \sum_{y} I(x+u, y+v) \right)$$

括号里的部分 $\sum_{x} \sum_{y} I(x+u, y+v)$ 的物理意义是：将原图 $I$ 整体平移了 $(u, v)$ 个单位后，计算全图所有像素的总和。既然只是平移，像素总数和每个像素的值完全没变，所以无论 $(u, v)$ 是多少，这个求和的结果永远等于原图的总能量 $E_{in}$。

因此：

$$E_{out} = \sum_{u} \sum_{v} K(u, v) \cdot E_{in} = E_{in} \cdot \left( \sum_{u} \sum_{v} K(u, v) \right)$$

因为卷积核的权重之和等于 1，代入得：

$$E_{out} = E_{in} \cdot 1 = E_{in}$$

**Q.E.D.（证明完毕）**

输出图像的总能量严格等于输入图像的总能量。由于像素总数不变，图像的全局平均亮度也就绝对不会发生哪怕 0.001 的偏移。

## 八、双边滤波 (Bilateral Filter)

### 高斯模糊的数学缺陷

高斯模糊是 **"色盲"** 的。它只看空间距离，不管像素长什么样，一律按距离分配权重。

想象人脸上的一个微观区域：左边是明亮的皮肤（像素值 200），紧挨着右边是黑色的睫毛（像素值 20）。当高斯模糊扫过这里时，皮肤像素会"借用"睫毛的黑色能量，睫毛也会"借用"皮肤的亮色能量。结果：皮肤变黑了，睫毛变白了，原本锐利的边界糊成了一团灰蒙蒙的过渡带——这就是为什么高斯模糊会让眼睛变得无神。

### 核心原理：双重高斯函数的相乘

为了拯救这个缺陷，数学家们在空间距离之外，引入了第二个高斯函数——**色彩范围权重 (Range Weight)**。这就是双边滤波的核心。

双边滤波的最终权重 $W$，是由两个独立的高斯权重相乘得到的：

$$W = W_{spatial} \times W_{range}$$

#### 第一重：空间距离权重 ($W_{spatial}$)

这就是高斯模糊。距离中心点 $(x_c, y_c)$ 越近，权重越大：

$$W_{spatial} = e^{-\frac{(x - x_c)^2 + (y - y_c)^2}{2\sigma_s^2}}$$

$\sigma_s$ (Sigma Spatial) 控制"空间跨度"。值越大，能模糊的物理范围越广。

#### 第二重：色彩差异权重 ($W_{range}$)

这是双边滤波的灵魂。它不再计算坐标的几何距离，而是计算像素颜色的欧氏距离：

$$W_{range} = e^{-\frac{(I(x, y) - I(x_c, y_c))^2}{2\sigma_r^2}}$$

- $I(x, y)$ 是邻居像素的颜色
- $I(x_c, y_c)$ 是中心像素的颜色
- $\sigma_r$ (Sigma Range) 控制"色彩容忍度"

### 见证奇迹的相乘

当我们在睫毛和皮肤的边界处滑动窗口，假设中心点落在皮肤上（200），邻居点落在睫毛上（20）。即使睫毛离中心点非常近（空间权重 $W_{spatial}$ 很大），但是它们的颜色差异极其巨大 $(200 - 20 = 180)$。巨大的颜色差代入 $W_{range}$ 的公式中，会产生一个无限接近于 0 的色彩权重：

$$\text{很大} \times 0 = 0$$

**结论**：不管你离我多近，只要你和我的颜色差异过大，我就认定你是"边界"，我绝对不和你混合。

反之，如果都是皮肤（颜色相近），色彩权重接近 1，那就按照正常的距离进行平滑。这就完美实现了 **"只磨皮，不糊眼"**。

### 底层实现的区别

| | 高斯模糊 | 双边滤波 |
|---|---|---|
| 卷积核 | 静态（算好一次，全图滑动） | 动态（每滑动到一个新中心点，必须重新计算整套权重） |
| 计算量 | 小 | 大得多 |
| 边界保持 | 差 | 优秀 |

## 九、频域滤波器：低通、高通、带通、带阻

### 9.1 基本框架

频域滤波的核心思路是：将图像通过傅里叶变换映射到频域，在频域中对各频率分量进行选择性的增强或抑制，再逆变换回空间域。整个过程可以概括为：

$$G(u, v) = H(u, v) \cdot F(u, v)$$

其中 $F(u, v)$ 是原图的傅里叶频谱，$H(u, v)$ 是滤波器传递函数，$G(u, v)$ 是滤波后的频谱。

由于图像的”低频”位于频谱的中心（经过 fftshift 后），滤波器通常以频谱中心为参考点设计。定义频率点到中心的距离：

$$D(u, v) = \sqrt{\left(u - \frac{M}{2}\right)^2 + \left(v - \frac{N}{2}\right)^2}$$

### 9.2 低通滤波 (Low-Pass Filter)

**功能**：保留低频分量，衰减高频分量。**效果**：图像平滑、去噪、模糊。

- **理想低通滤波器 (ILPF)**：一刀切——距离中心 $D_0$ 以内的频率全部保留，以外的全部归零。
  $$H(u, v) = \begin{cases} 1, & D(u, v) \leq D_0 \\ 0, & D(u, v) > D_0 \end{cases}$$
  缺点：空间域会出现”振铃效应” (Ringing Effect)，因为频域的硬截断对应空间域的 sinc 函数震荡。

- **Butterworth 低通滤波器 (BLPF)**：没有一刀切的陡峭截断，过渡带平滑。
  $$H(u, v) = \frac{1}{1 + \left(\frac{D(u, v)}{D_0}\right)^{2n}}$$
  $n$ 为阶数，$n$ 越大越逼近理想低通，振铃越明显；$n$ 越小过渡越平滑。

- **高斯低通滤波器 (GLPF)**：完全无振铃，但截止不如 Butterworth 陡峭。
  $$H(u, v) = e^{-\frac{D^2(u, v)}{2\sigma^2}}$$

### 9.3 高通滤波 (High-Pass Filter)

**功能**：保留高频分量，衰减低频分量。**效果**：边缘增强、锐化、细节提取。

高通滤波器可以由对应的低通滤波器直接推导：

$$H_{hp}(u, v) = 1 - H_{lp}(u, v)$$

- **理想高通**：$D(u, v) > D_0$ 为 1，否则为 0。
- **Butterworth 高通**：
  $$H(u, v) = \frac{1}{1 + \left(\frac{D_0}{D(u, v)}\right)^{2n}}$$
- **高斯高通**：$H(u, v) = 1 - e^{-\frac{D^2(u, v)}{2\sigma^2}}$

- **拉普拉斯频域算子**：$H(u, v) = -4\pi^2 D^2(u, v)$，是经典的高通滤波器，等价于空间域的二阶导数。

### 9.4 带通滤波 (Band-Pass Filter)

**功能**：仅保留某一特定频率范围内的分量，抑制低频和高频。**应用**：纹理分析、特定频率特征提取。

$$H_{bp}(u, v) = H_{lp_1}(u, v) \cdot \left(1 - H_{lp_2}(u, v)\right) \quad (D_1 < D_2)$$

本质是用一个低截止的低通减去一个高截止的低通（两者相减得到中间的环带）。

### 9.5 带阻滤波 (Band-Stop / Notch Filter)

**功能**：衰减特定频率范围内的分量，保持其余频率不变。**应用**：去除周期性噪声（老照片扫描网纹、摩尔纹、50Hz 电源干扰）。

$$H_{bs}(u, v) = 1 - H_{bp}(u, v)$$

理想带阻滤波器在频谱上”挖去”某个环形区域。在实践中，更常用的是 **陷波滤波器 (Notch Filter)**——它不是挖去一个环，而是在频谱特定位置（通常成对出现，代表某个单一频率的噪声）精确地置零，用于消除图像中规则的条纹噪声。

### 9.6 四种滤波器对比

| 类型 | 保留 | 衰减 | 视觉效果 |
|------|------|------|----------|
| 低通 | 低频 | 高频 | 平滑、模糊、去噪 |
| 高通 | 高频 | 低频 | 锐化、边缘提取 |
| 带通 | 中间某段频率 | 低频 + 高频 | 特定纹理提取 |
| 带阻 | 低频 + 高频 | 中间某段频率 | 去除周期性噪声 |

## 十、NumPy 广播机制 (Broadcasting)

### 10.1 什么是广播

广播是 NumPy 对不同形状 (shape) 的数组进行逐元素算术运算时，自动扩展数组维度的机制。它让你不需要手动复制数据就能让不同大小的数组”对齐”计算。

### 10.2 广播规则

从最后一个维度（最右侧）向前对齐两个数组的 shape，逐维比较：

1. **维度相等** → 兼容。
2. **其中一个为 1** → 兼容，该维会被”拉伸”以匹配另一个数组。
3. **两者不等且都不为 1** → 不兼容，抛出 `ValueError`。

缺失的维度会被自动视为 1。

### 10.3 示例

```python
# 标量与数组：标量被广播到整个数组
img + 50          # (H, W, 3) + () → 每个像素加 50

# 一维与二维
img + [10, 20, 30]  # (H, W, 3) + (3,) → 每个通道加不同值

# 尺寸为 1 的维度被拉伸
a = np.ones((3, 1, 4))   # shape (3, 1, 4)
b = np.ones((1, 5, 1))   # shape (1, 5, 1)
c = a + b                 # shape (3, 5, 4)
```

### 10.4 图像处理中的意义

- **亮度调整**：`img + brightness`，标量广播到全图。
- **逐通道操作**：如 `img * [0.299, 0.587, 0.114]` 计算灰度，广播避免逐像素循环。
- **向量化替代 Python 循环**：将 $O(H \times W)$ 的 Python 级循环转为 C 级的向量化运算，性能提升通常达到 10-100 倍。

## 十一、对比度与饱和度：灰度轴上的两种维度

### 11.1 对比度 (Contrast)

- **控制目标**：明暗差异（光的强度差异）。
- **数学定义**：图像所有像素亮度值的统计方差。方差越大，对比度越高。
- **几何运动**：沿灰度对角线（$R=G=B$）做一维拉伸。暗的更暗 ($\to 0$)，亮的更亮 ($\to 255$)。
- **适用范围**：彩色图与灰度图均有效。
- **降至最低 (0) 时**：图像变成一块纯粹的中灰色画板（所有像素趋于同一灰度级）。
- **极端案例**：纯黑白国际象棋棋盘——饱和度为零（无颜色），但对比度是完美的最大值。

### 11.2 饱和度 (Saturation)

- **控制目标**：色彩纯度（掺了多少”灰”）。
- **数学定义**：在 HSV 空间中，$S = \frac{\max(R,G,B) - \min(R,G,B)}{\max(R,G,B)}$。当三个通道值越接近（差值越小），$S \to 0$；当某通道极大而另一通道为 0 时，$S \to 1$。
- **几何运动**：垂直于灰度对角线向外扩散。离灰度轴越远，颜色越纯粹。
- **适用范围**：仅对彩色图有效。
- **降至最低 (0) 时**：图像变成黑白灰度图（所有像素 $R=G=B$）。
- **极端案例**：纯红色画布（所有像素 $255, 0, 0$）——饱和度最高，但对比度为零。

### 11.3 核心差异总结

| 维度 | 控制目标 | 几何运动方向 | 适用范围 | 降至最低 (0) 的效果 |
|------|----------|-------------|----------|-------------------|
| 对比度 | 明暗差异 | 沿灰度轴一维拉伸 | 彩色图与灰度图 | 纯灰画板 |
| 饱和度 | 色彩纯度 | 垂直灰度轴向外扩散 | 仅彩色图 | 黑白灰度图 |

## 十二、HSV 色彩空间：非线性几何投影

### 12.1 RGB → HSV 的非线性本质

RGB 到 HSV 的转换**不属于线性矩阵变换**。不存在任何一个 $3 \times 3$ 的常数矩阵能直接完成这个映射——因为它包含 $\max$、$\min$ 和除法运算，在数学上构成严格的**非线性分段投影 (Non-linear Piecewise Projection)**。

### 12.2 几何视角：从正方体到圆柱体

将 RGB 三维笛卡尔正方体沿 $R=G=B$ 灰度轴立起来，从正上方（纯白点向纯黑点）俯视，立方体的外轮廓投影成一个**正六边形**。HSV 空间基于此投影建立，采用**圆柱坐标系**：

- **V (Value, 明度)**：圆柱中轴线的垂直高度，$V = \max(R, G, B)$
- **S (Saturation, 饱和度)**：从中心轴向外辐射的极径，$S = \frac{\max - \min}{\max}$
- **H (Hue, 色相)**：绕中心轴旋转的极角，$0^\circ \sim 360^\circ$

六边形的 6 个顶点对应 6 种极限色彩，在极坐标系中拥有固定的绝对角度：

| 颜色 | 角度 |
|------|------|
| 红 (Red) | $0^\circ$ |
| 黄 (Yellow = R+G) | $60^\circ$ |
| 绿 (Green) | $120^\circ$ |
| 青 (Cyan = G+B) | $180^\circ$ |
| 蓝 (Blue) | $240^\circ$ |
| 品红 (Magenta = R+B) | $300^\circ$ |

### 12.3 RGB 与 HSV 之间并非双射

一个关键的反直觉事实：**RGB 到 HSV 是满射 (Surjection)，不是双射 (Bijection)**。

**奇点缺陷**：纯黑像素 $(0, 0, 0)$ 处，$V=0$，色度极差 $C = \max - \min = 0$。此时 $S=0$，但 $H$ 的分母为 $C$，出现**除零未定义**。

**多对一映射**：对于任何灰度像素（$R=G=B$），$C=0$，$S=0$。此时 $H$ 失去物理意义。反向映射时，$(H=0^\circ, S=0, V=1)$、$(H=120^\circ, S=0, V=1)$、$(H=360^\circ, S=0, V=1)$ 全部无差别地映射回 $(1, 1, 1)$——多组不同的 HSV 坐标对应同一组 RGB 坐标，这破坏了单射性 (Injectivity)。

> **代码实践**：实现 RGB → HSV 时必须用掩膜 (Mask) 显式处理 $C=0$ 的数学奇点，否则会出现 NaN 或运行时错误。

### 12.4 色相 H 的分段计算

根据哪个通道贡献了最大值 $V = \max(R, G, B)$，色彩六边形被划分为三个互夹 $120^\circ$ 的扇区。定义色度极差 $C = V - \min(R, G, B)$：

$$H' = \begin{cases} \text{Undefined}, & \text{if } C = 0 \\[6pt] \dfrac{G - B}{C} \pmod 6, & \text{if } V = R \\[10pt] \dfrac{B - R}{C} + 2, & \text{if } V = G \\[10pt] \dfrac{R - G}{C} + 4, & \text{if } V = B \end{cases}$$

最终：$H = 60^\circ \times H'$

#### 公式拆解

**1. 局部相对位移（以 $V=R$ 为例）**：颜色落在以红色 ($0^\circ$) 为中心的 $[-60^\circ, 60^\circ]$ 扇区内。$R$ 已到顶，具体偏向由 $G$ 和 $B$ 的较量决定。核心项 $(G-B)$ 除以 $C$ 做归一化（消去亮度影响，使暗红和亮红有相同的色相），得到无量纲比值 $\frac{G-B}{C} \in [-1, 1]$，恰好线性映射到 $[-60^\circ, 60^\circ]$。

**2. 全局相位偏移（$+2$ 和 $+4$）**：由于六边形被切成 6 段，每段跨 $60^\circ$，$H'$ 代表”以 $60^\circ$ 为单位的扇区编号”：
- $V=G$（绿色扇区，$120^\circ$）：基准编号 $2$，局部偏移由 $\frac{B-R}{C}$ 决定，范围 $[1, 3]$
- $V=B$（蓝色扇区，$240^\circ$）：基准编号 $4$，局部偏移由 $\frac{R-G}{C}$ 决定，范围 $[3, 5]$

**3. 逻辑闭环**：将扇区编号 $H'$ 乘以 $60^\circ$，完美还原为绝对角度 $H$。整个公式将非线性几何投影固化为严密的拓扑学逻辑——哪条通道最大，颜色就在哪个扇区；剩下两条通道的差值，决定在该扇区内的精确角度。
