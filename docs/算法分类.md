# 图像美化系统 — 算法分类

> 共 41 个算法函数，分为 9 个类别，按用户认知梯度排列。

---

## 一、基础调色（5）

全局亮度、色彩、色调的连续调节，参数影响整张图。

| 算法 | 函数 | 原理 |
|------|------|------|
| 亮度调节 | `adjust_brightness` | 全体素加偏移量 $\beta$ |
| 对比度调节 | `adjust_contrast` | 全体素乘系数 $\alpha$ |
| 饱和度调节 | `adjust_saturation` | 以灰度为基准线性缩放色彩偏离 |
| 直方图均衡化 | `histogram` | 累积分布函数映射到均匀分布 |
| 曲线调整 | `apply_curve` | Catmull-Rom 样条非线性映射，5 种预设 |

---

## 二、色彩转换（5）

改变图像的色彩模式或通道结构，属于"换模式"而非"调参数"。

| 算法 | 函数 | 原理 |
|------|------|------|
| 灰度化 | `to_grayscale` | BT.601 加权：$0.299R + 0.587G + 0.114B$ |
| 固定阈值二值化 | `binarize` | $I > T$ → 255，否则 0 |
| 伪彩色映射 | `apply_colormap` | LUT 灰度→彩色的分段线性映射 |
| 假彩色合成 | `synthesize_false_color_image` | 多光谱波段绑定到 RGB 三通道 |
| 通道置换假彩色| `false_color_channel_swap` | 交换 RGB 通道顺序产生特殊色彩 |

---

## 三、图像滤波（7）

空域与频域的平滑/去噪/边缘提取，均为全局操作。

| 算法 | 函数 | 原理 |
|------|------|------|
| 均值滤波 | `mean_filter` | 邻域算术平均 |
| 中值滤波 | `median_filter` | 邻域中位数，去椒盐噪声 |
| 高斯模糊 | `gaussian_blurring` | 高斯核加权卷积 |
| 低通滤波 | `lowpass_filter` | FFT → 保留低频 → IFFT，3 种掩膜 |
| 高通滤波 | `highpass_filter` | 低通互补：$H_{\text{HP}} = 1 - H_{\text{LP}}$ |
| 带通滤波 | `bandpass_filter` | 外圈低通 − 内圈低通，保留中间频段 |
| 带阻滤波 | `bandreject_filter` | 带通互补，抑制周期性噪声 |

---

## 四、噪点与锐化（4）

添加或抑制噪声，增强细节。

| 算法 | 函数 | 原理 |
|------|------|------|
| 添加高斯噪声 | `add_noise` (mode="gaussian") | 正态分布采样叠加 |
| 添加椒盐噪声 | `add_noise` (mode="salt_pepper") | 随机像素替换为 0 或 255 |
| 椒盐噪声(优化版) | `add_salt_pepper_noise_optimized` | 坐标采样替代概率矩阵，大图更高效 |
| USM 锐化 | `adjust_sharpness` | $I + \alpha \cdot (I - I_{\text{blur}})$ |

---

## 五、智能增强（5）

先检测后处理——通过掩膜精确定位目标区域，非全图一刀切。

| 算法 | 函数 | "智能"之处 |
|------|------|-----------|
| OTSU 二值化 | `otsu_binarize` | 自动遍历 0~255 最大化类间方差，免手动设阈值 |
| 双边滤波 | `bilateral_filter_manual` | 空间+颜色双权重，平滑噪点同时保留边缘 |
| 智能锐化 | `smart_sharpen` | Sobel 边缘检测 + 软蒙版，仅锐化边缘，平滑区不动 |
| 智能补光 | `intelligent_fill_light` | Sigmoid 暗区掩膜 + Gamma 校正，只提暗部不伤高光 |
| 高光增强 | `adjust_highlight` | 亮度+饱和度联合掩膜，精确定位高光区域增强光泽 |

---

## 六、艺术特效（3）

非写实风格化处理，产生视觉艺术效果。

| 算法 | 函数 | 原理 |
|------|------|------|
| 浮雕 | `emboss` | 邻域差分 $P_1 - P_2 + 128$，模拟凹凸纹理 |
| 毛玻璃 | `frosted` | 邻域随机像素采样，破坏连续性产生磨砂感 |
| 倒影图 | `create_reflection` | 垂直翻转 + 渐变透明度 + 水面背景色混合 |

---

## 七、几何变换（6）

图像的空间位置、尺寸、方向调整。

| 算法 | 函数 | 原理 |
|------|------|------|
| 旋转 | `rotate` | 绕中心反向旋转 + 最近邻插值 |
| 平移 | `translate` | 坐标平移，超出区域填黑 |
| 缩放 | `zoom` | 几何中心对齐 + 双线性插值 |
| 水平翻转 | `flip` | $(u, v) \to (w - u - 1, v)$ |
| 裁剪 | `shear` | 矩形区域像素拷贝 |
| 加框 | `add_border` | 等比缩放嵌入画框模板，支持位置微调 |

---

## 八、图像拼接（4）

两张或多张图像的合成。

| 算法 | 函数 | 方法 |
|------|------|------|
| 水平拼接 | `horizontal_collage` | 最大高度对齐 + 并排 + 白色填充间隙 |
| 垂直拼接 | `vertical_collage` | 最大宽度对齐 + 上下排列 |
| 经典拼接 | `stitch_images_classic` | SIFT + RANSAC + 单应性变换 + 加权融合（骨架） |
| AI 全景拼接 | `stitch_images` | UDIS++ (ICCV 2023)：ResNet-50 + TPS + U-Net 融合 |

---

## 九、AI 增强（3）

基于深度学习论文复现的端到端增强，需 GPU。

| 算法 | 函数 | 论文 |
|------|------|------|
| 超分辨率 | `super_resolve` | Real-ESRGAN (Wang et al., ICCV 2021)，4× 超分 + 预处理去噪 + 后处理锐化 |
| 旧照片修复 | `restore_old_photo` | 五阶段管线（FMM 修复 → 双边去噪 → CLAHE → 暗通道去雾 → USM 锐化） |
| 风格迁移 | `stylize` | Neural Style Transfer (Gatys et al., CVPR 2016)，VGG-19 + Gram 矩阵 + L-BFGS |
