## 一、需求全景分析

### 1.1 实验目的（8项）
1. 掌握数字图像的读取和存储方法（BMP/JPG/PNG，彩色+灰度）
2. 掌握图像基本几何变换（旋转、对称、缩放+插值）
3. 掌握图像的代数运算
4. 掌握数字图像的加噪与去噪方法
5. 掌握数字图像增强方法（灰度映射、直方图均衡化等）
6. 掌握数字图像的空域和频域图像增强方法
7. 掌握彩色图像的色彩增强、色彩模型转换和分析应用
8. 掌握数字图像的图像拼接技术及应用

## 三、各模块详细设计

### 3.1 core/io.py — 图像读写与显示
- `read_image(path)` → 自动识别格式，返回 numpy array
- `save_image(img, path)` → 根据扩展名自动选择编码
- `show_image(img, title)` → 调用 Matplotlib/OpenCV 显示
- 支持：彩色(RGB/BGR) ↔ 灰度自动转换

### 3.2 algorithms/noise.py — 加噪
- `gaussian_noise(img, mean=0, sigma=25)` → 高斯噪声
- `salt_pepper_noise(img, prob=0.05)` → 椒盐噪声
- `poisson_noise(img)` → 泊松噪声（可选拓展）

### 3.3 algorithms/denoise.py — 去噪（核心）
**空域滤波（至少1种）：**
- `mean_filter(img, ksize=3)` → 均值滤波
- `median_filter(img, ksize=3)` → 中值滤波
- `gaussian_filter(img, ksize=3, sigma=1)` → 高斯滤波
- `bilateral_filter(img, d=9, sigma_color=75, sigma_space=75)` → 双边滤波（保边去噪）

**频域滤波（至少1种）：**
- `fft_lowpass(img, radius=50)` → 傅里叶低通滤波
- `fft_highpass(img, radius=50)` → 傅里叶高通滤波
- `wavelet_denoise(img)` → 小波去噪（可选拓展）

### 3.4 algorithms/color.py — 色彩处理
- `rgb_to_gray(img)` → 彩色转灰度
- `gray_to_binary(img, threshold=127)` → 灰度转二值（支持 Otsu 自适应阈值）
- `pseudocolor(img, colormap='jet')` → 伪彩色增强
- `false_color(img, mapping=None)` → 假彩色增强（RGB 通道映射）
- `color_enhance(img, saturation=1.2)` → 饱和度调节

### 3.5 algorithms/enhance.py — 图像增强
- `linear_transform(img, alpha=1.0, beta=0)` → 线性灰度映射（亮度/对比度）
- `gamma_correction(img, gamma=1.0)` → Gamma 校正
- `histogram_equalization(img)` → 直方图均衡化（灰度图）
- `clahe(img, clip_limit=2.0, grid_size=8)` → 限制对比度自适应直方图均衡化
- `adjust_brightness(img, factor=1.0)` → 亮度调整
- `adjust_contrast(img, factor=1.0)` → 对比度调整

### 3.6 algorithms/geometry.py — 几何变换
- `rotate(img, angle, interpolation='bilinear')` → 旋转（支持 3 种插值）
- `flip(img, direction='horizontal')` → 镜像对称（水平/垂直/对角）
- `resize(img, scale, interpolation='bilinear')` → 缩放
- 插值方法：`nearest` / `bilinear` / `bicubic`

### 3.7 algorithms/beautifier.py — 美化特效
- `blur(img, method='gaussian', kernel=5)` → 虚化
- `emboss(img, kernel=None)` → 浮雕效果
- `frosted_glass(img, window=5)` → 毛玻璃效果
- `add_frame(img, width=10, color=(255,255,255))` → 加框
- `simple_collage(imgs, layout='horizontal')` → 简单拼图（支持彩色+灰度混合）
- `mirror_reflection(img)` → 倒影图
- `old_photo(img)` → 旧照片效果

### 3.8 algorithms/special.py — 特殊功能
- `super_resolution(img, scale=2)` → 超分辨率（可用插值模拟或预训练模型）
- `image_stitch(img1, img2)` → 图像拼接（SIFT/RANSAC）

### 3.9 gui/ — 图形界面
- 方案 A（推荐）：**Tkinter**，轻量、无需额外安装
- 方案 B：**PyQt5**，更美观但需要安装
- 主界面布局：
  - 左侧：原图显示区
  - 右侧：处理结果预览区
  - 上方：工具栏/菜单栏（功能分类下拉）
  - 下方：参数调节滑块/按钮

## 五、技术选型（实际）

| 组件 | 使用 | 理由 |
|------|------|------|

| 深度学习 | PyTorch + torchvision | UDIS++ 拼接、Real-ESRGAN 超分、VGG-19 风格迁移 |
| 显示 | — | Web 前端 Canvas 渲染 |
| GUI | Flask + HTML5/JS/CSS | Web 架构，无需安装客户端，跨平台 |
| 文档 | Markdown | 8 个 md 文件覆盖设计、算法、报告 |
| 版本控制 | Git | 当前分支 `no-opencv` |
